* Overview

Causal inference methods are available as ~causalinf~ submodules. To import a submodule, use:

# 
#+BEGIN_SRC python :exports code :results silent :tangle src-overview.py :cache yes :noweb no :session *Python* :linenums 1 :eval never
from causalinf import <submodule name>
#+END_SRC

Here are some examples:

#+BEGIN_SRC python :exports code :results silent :tangle src-overview.py :cache yes :noweb no :session *Python* :linenums 1  :eval never
from causalinf import did # (1)!
from causalinf import gcm # (2)!
from causalinf import iv  # (3)!
#+END_SRC

1. Load the Difference-in-Differences (DiD) module
2. Load the Causal Graphical Models (GCM) module
3. Load the Instrumental Variable (IV) module


The following methods and their respective submodule names are available (others may become available in the future):

#+BEGIN_SRC python :exports results :results table :tangle src-overview.py :cache yes :noweb no :session *Python* :linenums 1 :eval always
import causalinf 
import tidypolars4sci as tp

tab = tp.tibble()
i = 1
for module in causalinf.__all__:
    method = causalinf.__all_labels__.get(module, None)
    if method:
        desc = causalinf.__description__[module]
        tab = tab.bind_rows(tp.tibble({"Method":[f"{i}. [[file:../{module}/introduction/][{method}]]"],
                                       'Submodule name':[module],
                                       'Description': [desc]
                                       }))
        # print(f"{i}. {method:33} (submodule name: *{module}*)")
        i+=1
tab.to_pandas().set_index('Method')

#+END_SRC
