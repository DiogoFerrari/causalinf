* Overview

The following submodules (i.e., methods to identify causal effects) are available (other methods may become available in the future):

# 
#+BEGIN_SRC python :exports results :results output code org :tangle src-overview.py :cache yes :noweb no :session *Python* :linenums 1 :eval always
import causalinf 

i = 1
for module in causalinf.__all__:
    method = causalinf.__all_labels__.get(module, None)
    if method:
        print(f"{i}. {method:33} (submodule name: *{module}*)")
        i+=1
#+END_SRC
