# Docs rules

## Critical: org-mode export workflow
- Files in docs/ are generated by exporting from org-mode source files
- NEVER edit .md files in docs/ directly unless explicitly told to
- If documentation content needs to change, say which .org file to edit instead
- Exception: mkdocs.yml and any stub/index files that are not org exports

## MkDocs
- Theme: Material for MkDocs
- Config file: mkdocs.yml at project root
- Serve: `mkdocs serve`
- Build: `mkdocs build`

## Nav and structure
- Navigation is defined in mkdocs.yml under `nav:`
- When adding a new page, update mkdocs.yml nav AND note which .org file to create

## Writing style
- Clear and concise, written for researchers and scholars
- Code examples should be complete and runnable
- Use admonitions (note, warning, tip) for callouts

## Exporting org files
- To export a .org file to .md, run: `~/Dropbox/CienciasSociais/studies/computing/linux/ubuntu/emacs-org2md.sh <path-to-file>/file.org`
- Always run this after editing a .org file before building the docs
- Build the docs only when explicitly asked
- Never manually edit the resulting .md file
