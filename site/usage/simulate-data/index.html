    Simulate Data

    The submodule simulate contains many classes that allow simulating data from specific models. For details, see Documentation.

    The object with the simulated data contains additional information, such as the parameter values used in the simulation. Below is an example of simulated data from a Graphical Model. Here is the graph:

    1
2
3
4
5
    from causalinf import simulate
from causalinf import gcm

G = gcm.examples(which='Pearl Example 1.1 (a)')
G.plot()

    To simulate data from a linear structure model based on that graph, use:

    1
    sim = simulate.lsem(G)

    Here are the data and some relevant pieces of information stored in the sim object:

2
3
    print(sim.data.head())
print(sim.parameters_tidy)
print(sim.parameters)
